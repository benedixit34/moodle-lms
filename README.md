# LMS Backend

Backend API for a Learning Management System, built with Node.js, TypeScript, and Express.js, with Moodle integration through the Moodle Web Services API.

## Features

* User management
* Course management
* Course enrollment
* Quizzes and assessments
* Quiz attempts and submissions
* Moodle API integration

## Tech Stack

* Node.js
* TypeScript
* Express.js
* Moodle Web Services API
